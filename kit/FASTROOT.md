# FASTROOT — T0 plan for fastest root (KotH, one host)

The bottleneck is **not the exploit** — it is serial recon. Prepare root *before*
the foothold: lanes at T0, exploit pre-staged, credential-first.

## One command
```bash
bash ~/Projects/KOTH-OPS/kit/koth-fastroot.sh <IP> --spawn relay
```
`--spawn relay` prints ready relay calls (preferred). `--spawn cli` launches
lanes directly via `defex-ctf delegate` (background). `--dry-run` = no traffic.

## T0 timeline (target)
| T+ | Action |
|---:|---|
| 0 | quick scan (≤15 s) + full scan in bg + 3 lanes spawned |
| 10 | ports known; lanes already have them |
| 20–30 | web lane returns key/cred (robots/source/config/.git/upload/DB) |

Metrics: foothold ≤60 s, root ≤120 s, king ≤60 s after root.

## Lanes (exclusive scopes, one decision each)
| Lane | Role | Scope | Goal |
|---|---|---|---|
| 1 | extractor | local `state/<ip>/loot` | cred/key/flag from artifacts |
| 2 | web | web ports only | one injection/upload → RCE or cred |

| 3 | identity | 88/389/636/445/3268 (AD only) | anon LDAP / roastable cred |
| 5 | verifier | read-only (at root) | king bytes, guard, flags |

Lane briefs are generated by `delegate/swarm.py plan` into `state/<ip>/swarm/`.

## Relay call shape (preferred)
```
codex_relay(task="$(cat state/<ip>/swarm/LANE-2.md)", workspace="state/<ip>",
            direction="general", background=true, sync_artifacts=true)
```
- `background=true` — never block the critical path.
- `sync_artifacts=true` — otherwise the workspace is pruned on completion and
  the lane's `recon/*` is lost.
- `agy_relay` — neutral research only, no target traffic (offensive wording is blocked).

## Privesc lane specifics
- First action: map `uname -r`, `pkexec --version`, SUID, sudo, caps, timers.
- Then deploy the matching prebuilt exploit — **no compile/fetch on target**:
```bash
state/<ip>/loot/exploits/deploy.sh <ip> <key> <user> state/<ip>/loot/exploits/PwnKit 'id'
```
- PwnKit (CVE-2021-4034) covers CentOS/RHEL 7.x, Ubuntu 20.04, Debian 11.
- Keep `kit/exploits/` as the cache; add static binaries + a one-line usage.

## Steering / lifecycle
- One thread per front; steer with **deltas** (`session=<childID>`), never repeat the task.
- Deadline 90–120 s → artifact or NEGATIVE; kill a lane with no artifact.
- At root: **fresh** verifier thread (never resume the thread under check).
- Truth = `ps` + relay events during the run, `defex-ctf receipt <runid>` after.
  A milestone is a lead, not a fact (this run: "credentials recovered" → `creds: []`).
